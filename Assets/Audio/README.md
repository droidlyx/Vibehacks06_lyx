# Original Verdant sound effects

These six short effects were authored for this project through deterministic mathematical synthesis in
`Tools/generate_sfx.py`. There are no external recordings, sampled music, generated speech, external API calls, or
paid-service credits in their production.

| Asset       | Purpose                                       | Duration | Peak amplitude | RMS amplitude |
|-------------|-----------------------------------------------|---------:|---------------:|--------------:|
| AFX_Swing   | Soft band-limited air swish                   |  0.160 s |        0.19998 |       0.04359 |
| AFX_Hit     | Low damped impact with a soft noisy transient |  0.160 s |        0.22998 |       0.05540 |
| AFX_Pickup  | Two short clear harmonic chimes               |  0.220 s |        0.19998 |       0.06007 |
| AFX_Grow    | Warm rising fundamental and fifth             |  0.500 s |        0.19000 |       0.07773 |
| AFX_Offer   | Brief warm D-major offering chord             |  0.350 s |        0.19998 |       0.04017 |
| AFX_Restore | Bright ascending D-major completion chime     |  1.000 s |        0.22998 |       0.05505 |

All source WAVs are mono, 48,000 Hz, signed 16-bit PCM. Each has explicit fade-in/fade-out, zero-valued first/last
samples and measured peak below 0.25. The generator can compare regenerated bytes with the saved files using
`python Tools/generate_sfx.py --verify`.

Only actual collision surfaces tagged `AudioSurface.Stone` use stone footsteps. Generated
colliding rocks receive that tag; terrain defaults to dirt. No grass-specific sound is
claimed. Stationary, airborne, dead, dodging and wild actors do not produce these humanoid
footsteps. Each sound group has independent voice limits; audio variation does not consume
gameplay randomness. Ending a journey stops its music/environment components.

Four editable SoundClasses live under `/Game/Art/Audio/Runtime`: `SC_VerdantMusic` (-16 dB),
`SC_VerdantAmbience` (-6 dB), `SC_VerdantSFX` (-4 dB) and `SC_VerdantUI` (-10 dB).
These are initial relative gains; dirt/stone samples were first matched to -12 dBFS peaks.
The 188.080-second music is a full composition with fades, not a seamless musical loop.
Conflict and renewal BGM have not yet been supplied and are not fabricated by this change.

Reproduction:

1. `python Tools/prepare_runtime_audio.py` prepares 48 kHz PCM masters under ignored
   `Local/AudioRuntime`, using the existing local vendor library and installed Blender.
   `--help` lists path overrides. Source hashes, decoding and mastering details are saved
   in the runtime manifest.
2. Run `Tools/import_runtime_audio.py` through the connected editor's Python support.
   It imports only the manifest's assets, verifies their properties and writes
   `Saved/Audio/runtime-import.json`. It does not start PIE or take screenshots.
3. Compile the C++ module, then start a new Play session manually. Do not combine a
   failed/active Live Coding reload with legacy Hot Reload; see `AGENTS.md`.
