# 现场试玩与演示

双击项目根目录的 Play.cmd。它会启动已验证的独立构建与本地 AI；模型首次加载需几秒。旧版保留在 Builds/Windows，迭代版另放在 Builds/v0.2/Windows。

## 一条可用于路演的路线

1. 朝提示中的苔石果林移动，按住 E 收集。按 Q 食用，把镜头留在人物和身边植物上，观察体型连续变化；成长消耗真实食物，仍需决定给自己还是留给世界。
2. 靠近米芽按 T，提出“你愿意亲自带5份食物去母树吗”。看到答复后关闭窗口，观察她带着养分走过去，进度必须等实际到达才增加。
3. 可以挑战荒枝游民，或继续采集、协商。战斗胜利后靠近按 E，得到的是对方实际持有的食物。轻击可被打断；翻滚后半段会受伤。
4. 找岚石或陶恩协商捐粮、开放果林或取消分成。模型会依据当前状态回应，口头承诺不等于已经到账；NPC还可能被战斗打断。对方走远需重新靠近。
5. 到母树旁按 Shift+F 批量供奉。达到100份后看右侧“本季记录”：本局由谁出粮、谁存活、哪些果林免费开放、谁控制土地。向后走一点并抬头，可看到复苏的树冠。

这是展示路线，不是预设任务链。世界在交谈和赶路时继续运转，NPC的迁移、争夺与死亡会改变结果。可以重新开始，尝试自己夺取果林并关闭采集，再比较居民行动。

## 演示边界

自动回放在正常资源下完成过一局：先成长和战斗，再协商，三名NPC实际交付45份、玩家55份，形成全部免费开放的山谷。该回放知道路线，不能据此推断首次游玩的通关时间或所有对话都会成功。

R重开整局；对话中Enter发送、Esc关闭。原型没有存档。默认独立构建与本地AI已在本机验证，其他电脑需检查显卡驱动和运行依赖。
