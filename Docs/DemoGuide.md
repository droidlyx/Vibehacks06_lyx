# v0.3 试玩与演示

独立编辑器项目：E:/UE_projects/VerdantAccord_v03/Verdant.uproject，使用 UE 5.8.3 打开。默认地图为 /Game/Maps/Valley。编辑器内点击 Play 开始。

1. WASD 移动，鼠标观察，Shift 奔跑。按住 E 在可采集果林收集真实食物，Q 吃5份并逐渐长大。
2. 在允许采集的果林按 B 花费最多5份食物养护土壤。满肥力不扣粮。实际养护与母树供奉会积累协商依据，空口承诺无效。
3. 靠近居民按 T 对话。可请求带粮供奉、开放果林、同行或和平移交果林。面板显示当前条件；收到答复后查看实际行动状态。
4. 公共路线：帮助世界后请求各地主免费开放；管理路线：帮助世界或赠送真实食物后，请求米芽、陶恩移交果林，再用 G 切换免费、30%分成与限制采集。
5. 也可自由战斗：左键轻击、右键重击、空格闪避，击败后用 E 收取其实际粮食。体型影响力量与范围。
6. 母树附近 Shift+F 批量供奉，累计100份后记录居民生死、果林控制者、开放政策、贡献与生态。世界仍继续运转。

两条路线都已用正常资源、真实本地模型和引擎输入回放完成；没有赠送测试资源或瞬移。它们证明结果可达，不保证自由输入的每句协商都成功，也不是人工试玩记录。居民会拒绝或还价。

R 重开；对话 Enter 发送、Esc 关闭。无存档。v0.2 保留在 Builds/v0.2/Windows。
