# 山谷 HUD 视觉与维护说明

本轮 UI 以概念图中的暖日光、深绿树冠和秋叶为参考：深苔绿卡片承托暖象牙文字，旧金细线与植物徽记连接母树主题。信息沿屏幕四周组织，中央保留角色、道路和母树的视野。

## 视觉规范

调色板集中在 `Source/Verdant/VerdantHUDStyle.h` 的 `VerdantUI` 命名空间。下表是代码中的线性 RGBA 数值，不是网页 sRGB 色值。

| 名称   | 线性 RGBA                 | 用途                     |
|--------|---------------------------|--------------------------|
| Ink    | 0.94, 0.91, 0.79, 1.00    | 主要文字、关键数值       |
| Gold   | 0.86, 0.66, 0.32, 1.00    | 目标进度、食物、重点提示 |
| Muted  | 0.59, 0.66, 0.55, 1.00    | 次级说明                 |
| Panel  | 0.018, 0.038, 0.026, 0.94 | 深苔绿面板               |
| Leaf   | 0.38, 0.67, 0.38, 1.00    | 正常生命条               |
| Danger | 0.90, 0.30, 0.19, 1.00    | 低生命状态               |

圆角、边线、按钮普通/悬停/按下/禁用状态及进度条由原生 Slate 样式统一定义。`SCrest` 使用 Slate
线条绘制植物徽记；界面装饰没有新增位图素材或外部下载依赖。文字复用引擎提供的中文字体。低生命同时改变条色和文字，避免仅靠颜色辨认。

## 信息布局

| 位置       | 信息与行为                                                          |
|------------|---------------------------------------------------------------------|
| 左上       | 游戏标识、生命当前值/上限、食物、身高、力量、吸收中的养分或食用条件 |
| 右上       | 母树目标、实际送达养分/目标、母树距离与供奉提示                     |
| 右侧展开区 | 生态手记；复苏后展示冻结的本季结果及当前山谷状态                    |
| 左下       | 最新一条山谷见闻                                                    |
| 底部中央   | 附近目标、采集/分享/供奉条件、运送情况、即时通知及主要操作键帽      |
| 中央覆盖层 | 交谈、操作指南或死亡提示；交谈时收起常驻 HUD 并压暗场景             |

生态手记收起时不持续占据右侧大面积空间；母树复苏后的首次展示会自动展开记录。交谈保留居民态度、动机、可协商条件、玩家筹码、建议语句、滚动历史及输入框。建议语句只填入编辑框，发送才发起请求。生命耗尽时显示重新启程提示。

布局以 **1600×900** 为参考。最终缩放为 `min(视口宽/1600, 视口高/900)`，最低保护值为 0.25；自定义 `SDPIScaler` 除去 UE 已应用的
DPI 值，避免重复缩小。`SSafeZone`
使用标题安全区，常驻角落模块另有参考尺寸下的 32
单位内边距。横向或纵向多出的空间由角落锚点展开，卡片内部使用行列容器排布。正文在受限宽度中换行，手记及交谈历史有滚动区域。极小视口和特殊宽高比仍需通过真实截图检查文字可读性。

## 操作

| 输入        | UI 行为                                |
|-------------|----------------------------------------|
| Tab         | 展开/收起生态手记                      |
| PgUp / PgDn | 手记展开时向上/向下翻页                |
| H           | 展开/收起操作指南                      |
| Esc         | 收起手记/指南；交谈中结束交谈          |
| T           | 在原有距离及玩法条件允许时与居民交谈   |
| Enter       | 交谈输入框中发送当前非空内容           |
| R           | 原有重新开始行为；死亡界面提供对应提示 |

当前主要支持键盘与鼠标。交谈打开时聚焦输入框，发送或选择建议语句后返回输入框；交谈容器统一处理
Esc，按钮提供鼠标悬停和按下反馈。当前实现不能据此宣称完整手柄导航、手柄文字输入或触摸适配已完成。手记和操作指南是查看层，不会暂停世界模拟。

## 数据更新与维护入口

UI 显示现有角色、果林、世界及对话系统的真实状态。母树进度使用已结算的 `TreeNutrition`，承诺运送量继续单独显示；本季记录沿用原有不可回写的快照。

旧玩法代码直接修改字段，本轮采用 **10 Hz 兼容适配层**：定时读取展示数据，缓存格式化结果，只在文字变化时推送 `SetText`
，并定时设置进度。它减少了 Slate 绘制阶段的字符串格式化和世界摘要生成， **不是完全事件驱动的数据架构**
。可见性、输入处理、屏幕投影与战斗浮字等仍保留即时更新。后续若玩法统一提供变化事件，可替换这一适配层而保留控件结构。

| 文件                                 | 修改范围                                         |
|--------------------------------------|--------------------------------------------------|
| `Source/Verdant/VerdantHUDStyle.h`   | 调色板、字体、圆角样式、键帽、植物徽记           |
| `Source/Verdant/VerdantHUD.cpp`      | HUD 布局、数据适配、情境文案、对话焦点及显示逻辑 |
| `Source/Verdant/VerdantHUD.h`        | HUD 成员、定时器及界面状态                       |
| `Source/Verdant/VerdantHUDProbe.cpp` | 仅通过命令行启用的截图样例                       |

编译后需重新启动编辑器来加载新模块；已经运行的编辑器进程仍可能使用旧 DLL。尤其本轮涉及头文件成员变化，应使用完整构建与重启验证。

## 截图验证入口

以下命令从项目目录执行，使用本机 UE 5.8 安装路径。构建完成后运行无界面的独立游戏进程，验证入口会请求包含 Slate 的截图并自动退出：

```powershell
& 'E:/UE_5.8/Engine/Binaries/Win64/UnrealEditor.exe' 'E:/UE_projects/VerdantAccord_v03/Verdant.uproject' /Game/Maps/Valley -game -RenderOffscreen -unattended -NoSplash -ForceRes -ResX=1920 -ResY=1080 -VerdantHUDProbe
```

只捕获交谈界面：

```powershell
& 'E:/UE_5.8/Engine/Binaries/Win64/UnrealEditor.exe' 'E:/UE_projects/VerdantAccord_v03/Verdant.uproject' /Game/Maps/Valley -game -RenderOffscreen -unattended -NoSplash -ForceRes -ResX=1280 -ResY=720 -VerdantHUDProbe -VerdantHUDProbeCase=dialogue
```

可选样例为 `baseline`、`dialogue`、`low-health`、`death`、`restored`。未指定样例时依次捕获五种状态。输出位于
`Saved/Validation/HUD/<样例>-<宽>x<高>.png`，同目录文本记录截图请求。

这些样例会冻结模拟并填入指定状态；交谈文字是本地固定样例，不调用模型。截图只能用于检查布局和视觉状态，不能证明完整玩法、模型调用或输入路径正确。截图请求记录也不等同于人工视觉检查通过。

## 本轮验证（2026-10-31）

- UE 5.8 Editor Development 编译成功。为保留当前打开的编辑器，构建使用 `-ModuleWithSuffix=Verdant,1033`，模块清单已指向新
  DLL；重新启动工程即可加载。
- 1280×720、1920×1080、2560×1080 均完成五种状态截图，检查了中文可读性、边距、对话边界、数字不换行与可滚动季节记录。保存的图片尺寸均与请求一致。
- 三种分辨率下各通过五项 Slate 输入检查：交谈接管输入、找到按钮、按钮获得焦点、Esc 被路由处理、交谈关闭且恢复游戏输入。
- 原有 `-VerdantSmoke` 检查 16 项通过、0 失败，覆盖初始化、采集、成长、攻击、分享和母树复苏。
- 截图为固定状态样例；本轮没有验证联网模型对话、完整手柄导航或发布包。Tab/H/PgUp/PgDn 已实现，未进行桌面物理按键端到端测试。

检查日志位于 `Saved/Logs/HUD-final-*.log`、`Saved/Logs/HUD-smoke.log`。截图与输入结果位于 `Saved/Validation/HUD`。使用
`-ForceRes` 可避免后台窗口尺寸被桌面工作区限制。
