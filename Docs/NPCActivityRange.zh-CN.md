# NPC日常活动范围与食物刷新

每名NPC以自己的实际出生位置为日常活动中心，使用独立固定种子分配12～22米半径。不同角色的范围可以重叠，不是独占领地，也不会改变果林采集权限。

- 普通觅食只选择自身范围内、符合食物档位和权限要求的食物。附近没有合格目标时在范围内闲逛或等待下一次刷新。
- 偏离范围后用原有移动/绕行逻辑返回，不直接传送；回到内圈再恢复觅食，避免边界来回切换。
- 跟随、保护、战斗、避险和实际送粮等特殊行为可以临时越界。这些行为保留原活动中心和半径；解除、结束或失去对象后恢复原范围。
- 只有明确的迁居指令`leave`会迁往新的果林并设置新活动中心；正常跟随和停下不把玩家附近变成新家。
- 玩家不受NPC活动范围限制。

天然食物改为全场每30秒补齐已采空或缺失的食物点，继续使用原有各档数量和所属区域。在所属区域内重新随机选择合法位置；未吃完的食物保持位置和余量，不强制清空或补满。死亡掉落不再生。

关键实现：`VerdantNPC.cpp`、`VerdantPopulation.cpp`、`VerdantFoodWorld.cpp`；刷新间隔集中在`VerdantEconomyRules.h`的`FoodRefillInterval`。

验证：原生编译与链接通过。独立无渲染、禁用模型的短时检查确认20名NPC均有自己的中心和半径（本次种子实际半径12.049～21.830米）；首轮`VERDANT_FOOD_REFILL time=30.0`补回61/7/6/4个四档对象，无待补缺口，初始槽位仍为160。日志位于`Saved/Validation/npc-home-range-food.log`。特殊行动前后的中心不变与返圈优先级经过源码审查；没有自动运行跟随战斗玩法回放或截图。
