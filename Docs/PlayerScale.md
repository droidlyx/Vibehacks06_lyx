# 玩家初始尺度与移动速度

共享参数：`Source/Verdant/VerdantPlayerScale.h`。

- 初始 `BodySize=0.1`，以玩家 180 厘米基础胶囊高度计，身高 0.18 米。
- 最小一级地形单元约 4.94 米，约为初始身高的 27 倍。这是本轮的尺度选择，
  不代表每个细沟都已达到 18 厘米角色所需的几何精度；地面网格仍为 0.5 米。
- 正常玩家体型下限同步改为 0.1，避免出生或进食时被旧的 0.35 下限拉大。
- 缩放重置按键、HUD 起始身高与成长尺使用同一个初始值。
- 正常小体型也启用近距离镜头与较小的碰撞探针。

速度按体型线性变化。以原来 `BodySize=0.45`、身高 0.81 米的速度为参考，
乘 `当前 BodySize / 0.45`。2026-10-31根据慢速反馈将倍率从0.5调为1，即之前的两倍。正常行走和奔跑不再对当前体型使用
0.32／0.75 次幂。翻滚也同步线性缩放；加速度与刹车缩放保持响应时间相近。

| 玩家身高 | 行走速度约 | 奔跑速度约 |
|---|---:|---:|
| 0.18 米（初始） | 0.74 米/秒 | 1.50 米/秒 |
| 0.81 米（旧初始参照） | 3.33 米/秒 | 6.75 米/秒 |

最新奔跑参数单独设为初始体型150厘米/秒，使用 `SprintSpeed` 按当前体型与初始体型之比线性缩放。

按住左或右Shift奔跑。每帧读取当前Shift状态，对话期间不奔跑，关闭对话或复活后持续按住Shift可恢复奔跑；松开则恢复行走。

表格由参数公式估算，非试玩测量。攻击期间的减速仍保留；NPC 的原速度公式
不随本轮玩家速度需求改变。没有进行自动试玩或截图。
