# NPC体型：0.3～10米的对数分布

20名NPC的身高改为对数均匀分层采样。设`u`在0～1上均匀取值，则身高为：

`height = 0.3 * (10 / 0.3)^u`（米）。

当前20名角色覆盖20个等宽对数区间，每区间一个样本；最高区间保留一名10米个体。采用独立固定种子，样本随机分配给模型，起点的三名和平角色拿最小的三个样本。体型不会在游戏过程中随机变化，NPC仍不成长。

食物四档按实际身高判定，人数不再固定各5名。NPC使用独立的30～1000厘米体型限制；玩家现有成长及手动缩放规则单独保留。

巨型角色出生时，按实际大小向下扫描碰撞胶囊，确认地面坡度、支撑点和完整空间；最终胶囊与构造阶段胶囊均不穿透。4米以上角色及掠夺型角色远离玩家起点，居民间距计入双方碰撞半径。

参数和换算位于 `Source/Verdant/VerdantNPCScale.h`；分配与安全放置位于 `VerdantPopulation.cpp`。

纯C++规则检查位于 `Tools/tests/test_npc_scale.cpp`，覆盖端点、等对数间隔的几何比、代表性巨型尾部及玩家上限独立性。

## 当前种子与验证

默认种子731031实测20/20出生成功，20个对数区间各一名；最小0.33912米，最大10米，超过5米共4名，8米以上仅1名。起点ID1/4/6分别约0.339/0.360/0.440米。

冷编译通过，纯C++规则检查通过。独立无渲染、禁用模型的出生检查确认20名实际身高均落入所属对数区间，且最终碰撞胶囊无阻挡。日志：`Saved/Validation/npc-log-scale-final.log`，汇总：`npc-log-scale-results.json`。没有运行广泛玩法测试或截图。

同时修正了初始化顺序：引擎会先用默认胶囊调整落地高度，之后才应用NPC体型。现在只在出生阶段恢复已验证的实际尺寸落点，清除旧胶囊地面缓存，再进行最终检查，避免坡面上的新体型角色被误判为穿透。
