# 角色类型与关系类型设计库

本目录保存53种角色类型与关系类型的原始设计资料。当前源码已从中选择20种类型用于居民生成，并接入部分实例关系和共享送粮事件；其余候选与完整关系规格仍供后续实现，不表示整套设计库已完成。当前角色、动画、互动与性能仍待游戏内人工验收。

运行架构追加规格见[按需对话与持续行为](../ConversationRuntime.zh-CN.md)及本目录 `runtime_policy.json`：近距离收听 → StartLux相关性筛选 → DeepSeek按需回应/改变意图 → 规则持续执行。该规格更新了早期的“StartLux可选”定位；现有Excel的角色/关系内容不变，运行参数以追加规格为准。

## 主要交付

- `角色与关系设定.xlsx`：带真实模型图的角色类型表、性格与体型对白、主动互动、关系适配与请求判定、随机生成规则、模型证据。
- `角色模型图鉴.pdf`：便于逐页查看和选择外形的模型图册；完整文字以 Excel 为准。
- `characters.json`、`relations.json`、`generation_rules.json`：与表格对应的结构化设计数据。
- `Models/`：对应模型的原始内嵌缩略图，未经生成式重绘。
- `model_sources.json`：模型资产路径、源几何核对信息与图片哈希。

## 类型与实例

类型是人格、偏好、说话方式和独立模型的模板。实例具有自己的 ID、名字、大小、实际库存、位置、近期经历和关系。示例名不意味着只有一个该类型 NPC，也不意味着同类型实例共享记忆。

关系建立在实例 ID 之间。关系类型限定允许的 A/B 类型、方向、初始事实、互斥条件和数量上限。随机生成只从满足条件的候选中抽取；相对权重不是固定概率。无合法对象时可以保留孤立实例，不能强行编造关系或资源来凑数量。

大小独立于类型生成。大小变化影响威胁、求助、保护意愿和对白，不改变身份事实；不能把体型当成年龄、亲属辈分、职业或道德。

## 图片与模型核对范围

模型来自本机 `E:/UE_projects/ProjectTitan/Content/Characters`。资产类型、骨架引用和 LOD0 几何统计取自 uasset 的 Asset Registry；图片直接读取已保存的 Unreal ObjectThumbnail。未启动编辑器、调用编辑器截图、修改 Titan 或运行游戏测试。

原图多数为 256×256。灰白或偏暗是源文件保存的预览呈现，不足以断言模型没有材质；本次未重新渲染。角色的人设、中文名称和关系是为本项目新设计的，不是 Titan 原作设定。

已排除明确的部件、道具、同源换肤与重复修订版。不同模型可以共用骨架，但不能只靠换色或缩放冒充不同角色类型。源文件 MD5 相同且几何统计相同的明显变体未重复计入。

存在骨架或同骨架动画不代表已能执行本项目的攻击、跟随和受击；高面数、材质表现和动画适配需要后续逐项验证。角色库供选择，不建议一次把所有候选都作为高密度活动 NPC 加入场景。
